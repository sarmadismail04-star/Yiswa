# يسوى — Yiswa MVP

نسخة أولية قابلة للتشغيل لتطبيق "يسوى": تقييم السعر، مقارنة العروض، المفضلة والحساب.

## التشغيل

1. ثبّت Node.js.
2. ثبّت Expo CLI أو استخدم `npx expo`.
3. داخل المجلد شغّل:
   `npm install`
   ثم:
   `npx expo start`
4. افتح التطبيق عبر Expo Go أو المحاكي.
